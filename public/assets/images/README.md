# Drop your own photos here

The landing page (`home.html` and `index.html`) has two photo slots that
show a dashed placeholder until a real image exists at these exact paths:

- `home-left.jpg`
- `home-right.jpg`

Just add files with those names to this folder (any real photo — same
filename replaces the placeholder automatically, no code changes needed)
and push. Recommended: portrait orientation, at least 800×1000px, JPG or
PNG under ~500KB so the page stays fast.
